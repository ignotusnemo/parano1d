# 文件、端口与限制

## 默认路径

| 路径 | 用途 | 权限性质 |
|---|---|---|
| `~/.parano1d/parano1d.toml` | Core 配置 | 运营者 |
| `~/.parano1d/gui-settings.json` | GUI 偏好 | 本地 UI |
| `~/.parano1d/data/` | Core 与 GUI 节点默认数据 | 共识数据 |
| `DATA_DIR/wallet.key` | 256 位钱包主密钥 | 花费权限 |
| `DATA_DIR/wallet.receipts` | 已保存的外发收据 | 本地付款证据 |
| `DATA_DIR/wallet.labels` | 持久地址标签 | 仅本地显示 |
| `DATA_DIR/wallet.history` | 本地钱包历史 | 本地展示 |
| `DATA_DIR/wallet.native-pending` | 跨重启保留的原生提交活动 | 本地操作跟踪 |
| `DATA_DIR/native-media/` | 有界元数据和图像缓存 | 经过检查的显示数据 |
| `DATA_DIR/native-media/queue/` | 待发布记录 | 准备上传的资产材料 |
| `DATA_DIR/p2p_identity.key` | 稳定 libp2p Ed25519 身份 | 仅网络身份 |
| `DATA_DIR/peers.json` | 成功连接过的公网出站节点 | 发现提示 |
| `DATA_DIR/history-step-cache/` | 派生的本地证明矩阵缓存 | 可重建 |
| `DATA_DIR/snapshot-staging/` | 接收快照临时数据 | 永不作为规范 State |
| `DATA_DIR/parano1d-gui.toml` | GUI 管理的节点配置 | 私有节点 |
| `DATA_DIR/parano1d-node.log` | GUI 管理的节点日志 | 诊断 |

Windows 中的 `~` 表示用户配置文件目录。

Unix 上，`wallet.key` 和 `p2p_identity.key` 仅允许所有者访问。前者控制
资金，后者不具备花费权限。

<a id="wallet-artifact-storage"></a>
## 钱包本地数据

`wallet.receipts` 与 `wallet.history` 使用带校验和的本地日志。
普通保存只追加发生变化的收据或历史后缀，定期原子快照压缩过时记录。
导出的付款收据格式独立于这种本地存储格式。

仍支持读取原有 JSON 文件。第一次写入时创建日志，并将原文件保存为
`wallet.receipts.legacy` 或 `wallet.history.legacy`。已有同名恢复副本不会
被覆盖。`.legacy` 只保留转换时的数据，不包含后续活动。只支持 JSON 的
旧二进制程序不能读取日志格式。

启动时，完整帧必须通过校验和与结构检查。末尾未完成的追加会被记录并忽略，
之前已提交的帧保留。下一次成功写入修复不完整尾部。缺少初始快照或完整帧损坏
会使加载失败。这些是本地存储完整性检查，不是共识规则或花费授权。

## 端口

| 端口 | 绑定 | 用途 | 是否公开 |
|---:|---|---|---|
| TCP 9600 | `0.0.0.0` | libp2p | 是 |
| TCP 9601 | `127.0.0.1` | JSON-RPC | 否 |

远程外部挖矿只能通过受保护的私有或 TLS 传输使用 RPC。Bearer token
认证请求，但不加密传输。

## 合约文件与传输

| 工件 | 位置与用途 |
| --- | --- |
| `wallet.contracts.json` | GUI 钱包目录；公开合约库及本地名称 |
| `contract-activity/` | GUI 钱包目录；已保存本地操作 |
| `objects/` | 节点钱包目录；已跟踪条款、状态和回执 |
| `objects/terminals/` | 本地回执引用的共用已认证终端 |

与钱包秘密一起备份这些文件。密钥恢复权限，但哈希承诺无法重建丢失的公开
程序条款或旧回执。完整保留 objects 目录，使共用终端引用保持可用。

| 限制 | 数值 |
| --- | ---: |
| 区块递归终端 | 1,100,000 字节 |
| 一次性分叉来源响应 | 48 MiB |
| 普通付款回执 | 128 KiB |
| 合约回执 | 1,110,624 字节 |
| RPC HTTP 请求体 | 2,237,632 字节 |
| 合约实例查询 | 1…256 行 |
| 保存状态或回执的 RPC 分页 | 1…64 行 |
| GUI 显示近期操作 | 256 |

GUI 限制约束显示列表，保存的回执仍保留在存储中。按 30 秒目标，144 区块
周期名义上为 72 分钟，18 区块最终性窗口为 9 分钟，区块体及撤销保留为 21/18 分钟。

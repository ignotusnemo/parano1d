# 代币和 NFT 媒体

名称、代码、描述和图片属于公开元数据。原生代币定义或 NFT 项目将元数据哈希
记录在 State 中。钱包显示前会核对描述和图片。资产身份由代币 ID，或 NFT 的
集合 ID 与序号确定。

创建时选择本地 PNG、JPEG 或 WebP 图片，大小不超过 4 MiB。钱包将其转换为
静态 PNG：代币标志不超过 512 × 512，NFT 不超过 2,048 × 2,048 像素。
输入图片的尺寸上限为 4,096 × 4,096。

确认创建前，钱包先保存准备好的文件。创建确认后，钱包在后台将文件和公开
收据发送到配置的媒体服务。服务通过自己的节点验证收据，并核对准确的资产、
类型和哈希。发布队列会保留，钱包重启后继续尝试。

钱包默认使用 https://tradedata.parano1d.org。可通过 `NOID_GUI_MEDIA_ORIGIN` 指定其他媒体服务。

其他钱包下载相同文件，并依据自己节点的 State 验证元数据哈希、图片哈希、
尺寸和字节数。描述按普通文本显示。元数据采用固定字段和内容哈希。

可选项目网站也包含在元数据哈希中。链接仅允许不含登录凭据的 HTTPS 地址，
并仅在点击后通过外部浏览器打开。图片从配置的媒体服务获取。

媒体存储包含不可变的 `metadata/`、`images/` 和公开 `proofs/` 目录。
可在 Git 中保存这些文件的精确副本，恢复后再次验证哈希。备份钱包时保留
`native-media` 目录，其中包含本地文件和待发布队列。

媒体暂时不可用时，钱包显示资产 ID 和占位图。节点仍能验证所有权、余额、
转账和交易。

部署配置见[媒体服务指南](../reference/media-service.md)。

## 自动下载

右上角的 **External data** 默认关闭。选择 **On** 加载代币和 NFT 图片，
以及 DEX 价格历史。设置会保留到下次启动。关闭时显示占位图。
已缓存的名称和代码在两种模式下都可用。创建资产时发布所选媒体，
创建表单会直接预览本地图片。

DEX 当前价格始终来自自己的节点。External data 关闭时，实时曲线显示
打开代币以来的价格变化。开启后，钱包额外从服务加载已确认交易的价格蜡烛。
请求仅针对当前打开的代币。钱包在内存中保留最多 512 个区块的数据，
离开市场页面时释放图表。历史记录保存在服务器上。

**Settings → Interface → Clear asset cache** 清除已下载的名称和图片。
下载缓存最多占用 64 MiB，空间不足时淘汰旧文件。
已创建资产的媒体、待发布文件和收据会保留。

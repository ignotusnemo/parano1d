# NFT

**F3 → NFT** 包含 **My NFTs**、**Marketplace**、**My Listings** 和
**Create**。所有 NFT 操作都在这个工作区中完成。

## 浏览 NFT 和市场

**My NFTs** 将您的 NFT 按集合卡片及单个 NFT 卡片展示，也保留由您创建的集合，
方便以后继续添加。使用 **All**、**Collections**、**Single NFTs** 筛选，
或按名称、ID、序号搜索。打开集合可浏览其中的 NFT。

**Marketplace** 以相同方式展示有效出售挂单。集合卡片显示挂单数量及最低售价。
打开集合浏览挂单，或打开单个 NFT 核对并购买。**My Listings** 展示当前地址的挂单。

## 创建单个 NFT

在 **Create → Single NFT** 填写名称、图片、描述和可选的 HTTPS 项目网站。
创建需要两笔确认的交易，每笔各有网络手续费：

1. **Prepare, 第 1/2 步：** 核对并确认准备交易。确认后，该项显示在
   **My NFTs** 中的准备卡片内。
2. **Mint, 第 2/2 步：** 核对并确认铸造。确认后，NFT 显示在 **My NFTs**，
   可以发送或挂单出售。

表单和提交状态显示当前步骤。**Complete NFT** 可继续完成已准备的 NFT，
重启钱包后也可继续。

## 创建集合并添加 NFT

1. 在 **Create → Collection** 输入名称、可选封面、描述和 HTTPS 网站，
   核对并确认创建。
2. 从 **My NFTs** 打开已确认的集合，选择 **Add NFTs**。
3. 一次选择多张 PNG、JPEG 或 WebP 图片。钱包为每项建议名称；可分别修改
   名称，并设置这一批共同的描述和网站。
4. 核对数量、序号范围和网络手续费，然后确认。整批 NFT 在同一笔交易中铸造。

集合无需设置总量上限。只有创建者可以继续添加 NFT，现在或以后分批均可。
每项有独立的图片、元数据承诺、序号和可转移的所有权。销毁不会使序号可被重新铸造。

节点报告单笔交易的批量上限。当前配置在仅使用一个 NOID 资金输入时支持
最多 122 项；资金由许多小额输出组成时，可能需要减小批量。生成证明前，
核对步骤会检查实际所需页数和手续费。每张源图片最多 4 MB，整批准备后的
图片内存最多 128 MB。需要更多 NFT 时，向同一集合再铸造一批即可。

集合有自己的已承诺公开描述。每个 NFT 单独承诺名称、描述、网站及图片内容。
钱包核对显示数据与承诺；经过验证的 State 决定创建者权限、当前所有权和交易条款。
图片由已配置的[资产媒体服务](asset-media.md)提供。

## 发送或销毁

在 **My NFTs** 打开 NFT，选择 **Send**，核对接收地址和网络手续费。
操作转移该项 NFT 的所有权。

**Burn** 永久销毁该项，其序号不能再次铸造。NFT 不使用同质化代币的储备
赎回机制。

发送、销毁、挂单、购买和取消使用当前工作区上方的对话框。
关闭或按 **Esc** 返回原来的选择。

## 挂单与购买

打开 **Marketplace → List NFT**，选择自己可出售的 NFT 并输入 NOID 价格。
核对手续费后确认。也可以在 **My NFTs** 打开 NFT 并选择 **List for sale**。
交易确认后，挂单会出现在 **My Listings** 和 **Marketplace**。

**My Listings** 分别显示每个 NFT 的价格、到期高度及 **Remove listing** 按钮。
其搜索和筛选独立于 **My NFTs**。

挂单从创建高度起持续 2,880 个区块，按目标出块时间约为一天。
挂单持有 NFT 及 0.1 NOID 的挂单额度，创建网络手续费单独显示。

买家从 **Marketplace** 打开挂单，核对准确的 NFT 和价格后确认。付款和
NFT 所有权在同一笔交易中原子转移。卖家收到售价和挂单额度。如果其他买家
已先消费该挂单，节点会拒绝再次消费同一实例。

使用 **My Listings → Remove listing** 取回未售出的 NFT，以及扣除取消手续费后的
剩余挂单额度。确认后可以按新价格重新挂单。销售确认后，NFT 属于买家。

操作记录和保存的收据在重启后保留。请从 **Receipts** 导出重要 NFT 收据。
当前所有权可从 State 恢复；导出的收据在区块体裁剪后继续证明历史操作。
同时保留钱包备份与媒体描述。

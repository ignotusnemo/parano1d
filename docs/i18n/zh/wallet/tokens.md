# 代币与交易

**F2 → Tokens** 包含 **My Tokens**、**Launchpad**、**DEX** 和 **Create**。
钱包通过自己的节点验证余额并执行原生规则。`getNativeProtocol` 返回原生
规则是否已激活。

## 创建代币

进入 **Create**，填写名称、代码和整枚代币的发行量，然后核对操作。
图片可选。最低发行量为 100,000 枚。发行量在创建时固定，创建者没有后续增发
或提取持有人储备的操作。

可填写 HTTPS 项目网站。链接包含在经过验证的元数据中，仅在点击后通过外部浏览器打开。

可在 **Initial buy** 中填写创建时购买的代币数量；此项可选。
预览分别列出储备存入额、首次购买费用和网络手续费。每整枚代币需提供 0.001 NOID：
100,000 枚需 100 NOID，500 万枚需 5,000 NOID。确认前请核对 NOID 总支出。

创建和首次购买在同一笔交易中确认。购买的代币直接归创建者，公开交易从
该次购买后的曲线位置和价格开始。首次购买按标准曲线计价。发行量的 60%
用于曲线销售，剩余 40% 在毕业时进入永久 DEX 流动性。若创建时购买全部
曲线份额，则立即启动永久 DEX 池。留空表示创建时不购买。

例如，发行 100,000 枚并购买其中 10,000 枚，需要 100 NOID 储备、
38.888889 NOID 购买费用，另加网络手续费。

## 买入和卖出

**Launchpad** 提供图片卡片、搜索和 **New**、**Top Gainers**、**Graduated**
筛选。**Create Token** 按钮进入创建表单。点击曲线代币卡片，在 Launchpad
内打开图表、代币信息和交易表单。毕业代币保留在 **Graduated** 列表，点击后
进入 DEX。**DEX** 有独立的图片卡片目录、搜索、分页，以及 **Liquidity**、
**Top Gainers**、**Newest** 排序。**Back** 返回原目录并保留搜索、筛选、
页码和滚动位置。涨幅相对于标准曲线起始价格计算；Newest 按代币创建顺序，
Liquidity 按池中 NOID 储备排序。

从 **Launchpad** 或 **DEX** 打开代币，选择 Buy 或 Sell，输入支出数量。
核对预计收到数量、最低收到数量、手续费和有效高度。预估包含本节点已知的
待处理交易。新订单到达时预估可能变化，但您授权的最低数量保持固定。

一个区块可以执行多笔交易。每笔使用上一笔执行后的市场储备或曲线状态。
成交必须满足授权的最低数量；无法满足条件的订单不会花费其输入。
区块确认后可看到最终成交。

未成交订单可在队列中等待至有效期结束。默认有效期覆盖接下来的四个候选
区块高度；以 30 秒区块间隔计算约两分钟。等待期间，钱包在本地保留未花费
的输入。到期后节点移除订单，钱包刷新时解除保留。未成交订单不收取网络
手续费。在一个节点上移除记录，不会撤销其他节点上仍有效的订单。

曲线起始边际价格约为每枚 0.00333333 NOID，毕业时为 0.01 NOID。
500 万枚发行量的毕业门槛为曲线累积 20,000 NOID；100,000 枚的门槛为
400 NOID。持有人储备独立保存，不计入这些金额。

毕业自动完成，资产 ID 和持有人余额保持一致。DEX 对输入数量收取 0.3%
手续费，并向上取整至基础单位；网络手续费单独列出。

## 发送和销毁

Main 默认选择 NOID，下拉框也列出活动地址持有的代币。在 Main 打开
**Send** 并选择代币，或使用 **My Tokens → Send**。核对准确的资产 ID、
接收地址和数量；相同代码不代表同一资产。

发送和销毁表单显示在列表上方。关闭或按 **Esc** 返回原来的搜索与选中代币。
发送、销毁和卖出时，**MAX** 填入可用的全部数量，排除锁定和已预留数量。

**Burn** 在同一笔交易中销毁选定代币并返回相应比例的 NOID 储备。
核对赎回金额和网络手续费。取整余数留在剩余持有人的储备中。

## 活动、收据与图表

待处理操作在钱包重启后保留。新的预览不会自动替换已经授权的订单。
**Receipts** 区分普通付款与原生操作，并提供筛选和排序。请导出需要保留的收据。

Launchpad 根据经过验证的市场 State 绘制曲线和当前位置。
DEX 显示当前价格、池中储备和来自自己节点的实时价格曲线。
曲线从打开代币时开始，随确认后的 State 更新。**External data**
增加来自服务的交易历史。可显示 120 或 480 个区块。
蜡烛记录包含市场费用的实际成交价格，图表仅在当前市场的有界内存中保留。

![原生钱包中的 DEX 历史与实时价格](../../../assets/wallet/v2.1-dex.png)

自动价格容差默认为 10%。可以填写最低接收数量设置自己的成交下限。
提交后面板显示等待确认，订单确认且余额更新后自动关闭。
点击 **Close** 返回交易表单，订单状态可在 **Receipts** 查看。

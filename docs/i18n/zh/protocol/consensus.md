# 共识

Parano1d 只接受同时满足原生区块头规则、递归 [`HistoryStep`](../reference/glossary.md#historystep) 关系与[工作量证明](../reference/glossary.md#proof-of-work)的区块。[分叉选择](../reference/glossary.md#fork-choice)在所有有效候选链之间比较[累计工作量](../reference/glossary.md#cumulative-work)，同时保留具备[硬最终性](../reference/glossary.md#hard-finality)的前缀。

源代码是共识的规范定义。本规范描述稳定规则集及其边界。

## 候选区块有效性

子区块只有满足以下全部条件，才能扩展父区块：

1. `prev_block_hash` 等于父区块含 nonce 的区块 ID；
2. `height` 精确等于 `parent.height + 1`；
3. 时间戳大于前 11 个区块头的过去时间中位数，并且最多领先本地时钟 120 秒；
4. `difficulty_target` 等于从规范历史精确推导的 ASERT 目标值，且不得低于协议难度下限；
5. Poseidon2b PoW 摘要严格小于按小端序解释的目标值；
6. 物理区块编码及全部交易组均为规范形式；
7. 强制主要奖励与任何到期开发付款金额精确；
8. [交易周期（epoch）锚点](../reference/glossary.md#transaction-epoch-anchor)当前有效；
9. 区块内部不存在输入或输出冲突；
10. 手续费、价值守恒、分配计数器与槽位写入精确；
11. `log_slots` 遵循最终性扩展规则；
12. 转换后 State 计数器与根等于区块头承诺；
13. 所提供的 `HistoryStep` 终端验证通过，并绑定无 nonce 语义区块头。

直接接纳候选区块时，区块与匹配终端作为一个整体接受。认证追赶同步也可以先验证精确后缀链尖的终端，再导入其递归关系覆盖的链接区块体。每个区块体仍须满足上述原生规则。候选区块不能只凭区块字节和工作量证明获得接纳。

## 分叉选择

每个有效区块头按其目标值贡献工作量。累计工作量最大的候选链成为规范链。

若两个候选链的累计工作量相同，则链尖区块哈希按字典序较小者胜出。该决胜规则是确定性的；到达顺序和对等节点 ID 均不起作用。

## 硬最终性

只有最近 18 个区块的窗口可以重组。任何会改变具备最终性的前缀的候选链都不能参与分叉选择。回滚深度必须严格小于 18，因此最大可接受重组为 17 个区块。

硬最终性还把 State 扩展测量与临时分叉隔离。用于扩展的 18 个区块头占用率窗口结束于[最终性边界](../reference/glossary.md#finality-boundary)，而非链尖。

这是协议规则，而非依赖社会共识的检查点。所有节点都根据高度推导出同一边界，并拒绝更深的替代链。

## 难度

已接受区块之间的目标间隔为 30 秒。证明准备、nonce 搜索与区块传播共同占用
这一完整间隔。[ASERT](../reference/glossary.md#asert) 使用六区块参考周期与 180 秒半衰期调整目标值。
目标值编码为 256 位小端序整数。

从高度 210,537 的 v2 激活起，验证过程根据规范锚点和父区块头推导唯一精确的目标值。
同一父区块的子区块目标值相同，不受各自时间戳影响。矿工不能在某个允许范围内自行选择难度。

## 交易时钟

用户交易绑定到每个 144 区块交易周期（epoch）起点的区块 ID。边界区块仍接受前一个交易周期锚点；新锚点从下一个子区块开始生效。

对于子高度 `C > 0`，锚点高度为：

```text
floor((C - 1) / 144) × 144
```

该时钟独立于六区块 ASERT 参考周期。它限制重放和过期内存池交易的寿命，同时避免把钱包授权绑定到每一个新 State 根。

## 本地策略不是共识

节点可以自行选择转发或挖掘哪些可接受交易。默认内存池使用最小及动态手续费策略、冲突预留和有界资源。只要交易已经出现在有效区块中，这些本地选择就不能使其失效；唯一例外是共识明确检查同一最小手续费公式的部分。

同理，发布版节点要求连接一个[已完成身份认证的对等节点](../reference/glossary.md#authenticated-peer)后才允许挖矿。这是防止隔离的运维保护，不是区块有效性投票。

## 创世与网络身份

公网只有一个编译进二进制的链起点、网络魔数与协议标识。节点不会与对等节点协商共识参数。来自其他网络的数据在父区块、身份或证明检查阶段即会失败，无法成为规范 State。

## 按高度选择规则

主网 v2 从 H210537 起适用。候选高度同时选择证明矩阵库、资源预算、30 秒间隔及
按高度补贴。首个新证明绑定所选前驱；跨边界重组必须替换来源并回滚孤块合约转换。
ASERT 按各高度规则累加理想间隔。周期、最终性及保留数量仍为 144、18、42、36
个区块。合约分支使用纳入高度。

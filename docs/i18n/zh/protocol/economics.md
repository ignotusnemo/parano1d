# 网络经济

**区块高度决定发行。活 State 占用率决定持久存储成本。** NOID 用于支付网络
费用、支持已发行代币，并作为 launchpad 与原生 DEX 的计价资产。

## 单位

```text
1 NOID = 1,000,000 μNOID
```

代码为 NOID，钱包使用 ①。共识使用精确整数微 NOID。永久每块 1 NOID 补贴
支持尾部发行。

## State 效率

占用率提高净新增活槽位的费用，该部分销毁。合并释放槽位，避免增长收费。
输入输出费用按照实际操作规模计算。合约、代币和 NFT 使用共同活 State 记账规则。

## 开发分配

截至区块 **3,223,778**，补贴分配为：

- 90% 给矿工。
- 5% 给 O(1) Network Fund。
- 5% 给 Parano1d Lab。

之后区块补贴全部给矿工。扣除 State 增长销毁后的网络费由矿工领取。

基金按 2,880 个区块结算，首次付款高度为 213,416，最后不完整间隔在高度
3,223,778 结算。共识根据间隔与奖励档位推导强制系统付款。在 16 NOID 档位，
矿工补贴为 14.4 NOID，每个基金每完整间隔获得 2,304 NOID。这些份额属于总补贴分配。

## 市场费用与支持

创建代币时每整枚存入至少 0.001 NOID 支持。持有人销毁时按比例赎回储备。
交易流动性保存在独立 State 对象。

DEX 收取输入的 0.3%，向上取整至基础单位，费用保留在池储备。网络费单独显示。
曲线、毕业和准确公式见[原生金融](native-finance.md)。

## 手续费

最低交易手续费包括：

- 每笔逻辑交易 5,000 μNOID；
- 每个有效输入 100 μNOID；
- 每个有效输出 700 μNOID；
- 每个净新增已占用槽位 2,500 μNOID，再乘以占用压力倍数。

压力倍数为：

| 父 State 占用率 | 倍数 |
|---:|---:|
| 低于 50% | 1× |
| 50% 至低于 75% | 2× |
| 75% 至低于 90% | 4× |
| 90% 及以上 | 8× |

[State 增长费](../reference/glossary.md#state-growth-fee)会被销毁。基础费、输入费、输出费以及自愿追加的手续费可由矿工领取。

把多个输入归集为一个输出会缩减 State，因此不支付 State 增长费。

## 动态转发下限

共识手续费与本地转发策略相互独立。动态下限取 5,000 μNOID 与本地内存池最近接纳的 50 笔交易之中位手续费的 90% 两者中的较大值，不代表全网手续费估计。

只有出现压力时才启用较高下限。交易数量或保留字节数达到各自限制的 80% 即启用；两者都严格低于 50%，或内存池清空时，重置为默认值。两道阈值之间保留当前压力状态。现有的 1,024 笔交易和 384 MiB 限制不变。

本地转发下限上升本身不会驱逐已经接纳的交易。父 State 占用率导致共识最低手续费上升则不同，正常的新区块清理会移除不再满足该最低值的交易，并释放其本地预留。

钱包 Auto 根据实际交易形状、当前父 State 占用率与本地转发下限计算手续费。接纳之前收到本地手续费拒绝时，Auto 可在现有三次提交尝试内重新规划。手动手续费与用户已确认的归集报价不会被自动提高。不增加对等节点手续费轮询，也不承诺在其他节点的任意策略下都能确认。

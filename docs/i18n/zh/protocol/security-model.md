## 证明的内容

接受的终端覆盖精确输入实例、输出空槽、价值守恒、手续费、发行、合约策略及
整数程序转换、后 State 根和递归祖先链。普通输入需要所有者秘密；合约输入
需要由承诺策略和纳入高度选定的活跃授权。持有授权秘密不能绕过程序、分支权限或金额限制。

钱包证明绑定逻辑交易的秘密知识，矿工证明公开关系和父链接，节点验证并应用结果。
有效 nonce 无法修复无效证明。

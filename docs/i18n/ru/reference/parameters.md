# Справочник параметров протокола

Полная [таблица консенсуса](../protocol/parameters.md) содержит параметры
протокола. Интервал блока равен 30 секундам. Small m23: 63 страницы / 504 входа /
63 вызова, включаемый вручную Large m24: 206 / 504 / 63, автоматический Native
m24: 63 / 504 / 63 с native finance. Пределы действуют вместе.

| Тема | Справочник |
| --- | --- |
| Время, окна, State, сетевые пределы | [Параметры консенсуса](../protocol/parameters.md) |
| Эмиссия и комиссии | [Экономика сети](../protocol/economics.md) |
| ABI, программа и счётчики | [Ядро контрактов](../contracts/core.md) |
| Предпосылки и точный расчёт доказательств | [Модель безопасности](../protocol/security-model.md) |
| Реальные затраты построения и проверки | [Производительность](performance.md) |

`paranoid_getContractProtocol` возвращает установленные пределы и статус
runtime. Поле трассы — GF(2^128), поле широких вызовов — GF(2^256), множество
вызовов со следом один имеет размер 2^255. C1 использует 65 запросов кошелька
и 133 History. Poseidon2b: ширина 4, S-box x^7, 8 полных и 58 частичных раундов.
Эти параметры алгоритма не являются гарантией пропускной способности.

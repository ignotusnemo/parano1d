# Майнинг через Core

Для майнинга используйте ноду Core или внешний вычислитель. В кошельке
доступны Main, Tokens, NFT, Receipts, Scope, Contracts и Settings.

## Встроенный майнер Core

Проверьте оборудование и выберите бюджет CPU для встроенного майнера:

```sh
parano1d --check-hardware
parano1d --mode miner --cpu-threads 6
```

Core строит рекурсивное доказательство блока и ищет подходящий nonce.
Для одновременной работы Core и кошелька используйте отдельную папку данных
майнера. Новые награды получает активный или явно заданный адрес выплаты.

## Внешние вычислители и пулы

Нода бэкенда строит доказательство и выдаёт неизменяемый шаблон PoW.
Вычислители перебирают nonce и отправляют найденное решение. Доказательство
остаётся на бэкенде, а вычислители используют тот же алгоритм PoW.

Развёртывание описано в разделах [встроенный майнинг](../operate/internal-mining.md)
и [внешний майнер](../operate/external-miner.md). Бюджеты доказательств приведены
в [обзоре майнинга](../mining/index.md).

Кошелёк получает подтверждённые награды через свою проверяющую ноду.
Main показывает доступные выходы NOID. Scope открывает сохранённые блоки и
постоянные заголовки.

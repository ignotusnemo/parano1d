# Настройки

Откройте настройки клавишей `F8`.

![Настройки кошелька](../../../assets/wallet/settings.png)

## Секрет

Вкладка «Секрет» показывает режим текущего мастер-секрета и предоставляет
явные операции обслуживания:

- экспорт текущего секрета из 64 шестнадцатеричных символов;
- импорт существующего секрета;
- замена секретом из пикселей фотографии;
- генерация нового секрета.

Замена полностью меняет производные адреса. Если текущий секрет управляет
средствами, которые нужно сохранить, сначала экспортируйте его.

Секрет — не обычная настройка приложения. Для этих операций кошелёк
останавливает встроенную ноду, атомарно обновляет защищённый файл ключа и заново
запускает кошелёк с новым секретом.

## Нода

В настройках ноды можно:

- выбрать каталог данных;
- задать уровень журналирования;
- перезапустить ноду после изменения параметров, требующих перезапуска.

Встроенное окно показывает ограниченный хвост журнала ноды. Текст можно
выделить и скопировать для диагностики. Отдельное
постоянное хранилище логов для этого не создаётся.

Смена каталога данных переключает приложение на другую базу и другой
кошелёк. До применения внимательно проверьте путь.

## Сеть

Сетевые настройки задают:

- адрес прослушивания P2P;
- дополнительные адреса начальных нод.

По умолчанию P2P слушает `0.0.0.0:9600`. Встроенное DNS-обнаружение работает
без пользовательских записей.

Не делайте внутренний RPC доступным из сети. GUI и нода общаются локально.

## Интерфейс и внешние данные

Переключатель **External data** в заголовке управляет изображениями токенов
и историей цен. Изначально он выключен. Подсказка: **Load token images and
price history**. State рынка и текущая цена поступают из локального узла
в обоих режимах.

**Interface → Clear asset cache** очищает загруженные изображения, метаданные
и кеш графика. Кеш изображений ограничен 64 MiB. Подготовленные загрузки,
квитанции и ключи сохраняются. См. [медиа активов](asset-media.md).

# Резервное копирование и восстановление

Мастер-секрет и чеки восстанавливаются по-разному. Сохраняйте их отдельно.

## Мастер-секрет

256-битный мастер-секрет создаёт все адреса и даёт право расходовать их
средства. Резервной копией может служить:

- экспортированная строка из 64 шестнадцатеричных символов;
- точный оригинал фотографии, использованной для получения секрета из пикселей.

Храните копию офлайн. Прежде чем полагаться на неё, проверьте совпадение
короткого Key ID.

Локальный файл `wallet.key` не зашифрован паролем. На Unix он создаётся с
правами `0600`; границей безопасности остаются учётная запись операционной
системы и шифрование накопителя.

## Восстановление по фото

Только полностью одинаковые декодированные пиксели дают тот же секрет.
Сохраните исходный файл. Миниатюра, облачный предпросмотр, снимок экрана или
копия из мессенджера для восстановления не подходят.

Метаданные не важны. Изменённые пиксели создают другой кошелёк.

## Чеки

Файл `wallet.receipts` содержит чеки исходящих платежей. Он не выводится из
мастер-секрета и намеренно очищается при импорте
другого секрета.

Если нужен полный локальный журнал платежей, копируйте этот файл вместе с
мастер-секретом. Отдельный чек также можно экспортировать в виде
самодостаточного текста.

## Что восстанавливает импорт

Импорт возвращает:

- детерминированное получение адресов;
- текущие UTXO найденных адресов;
- право расходовать эти UTXO.

Импорт не возвращает:

- локальные метки адресов;
- чеки, оставшиеся только на другом устройстве;
- удалённые исторические транзакции без сохранённого чека;
- созданные адреса за пределами непрерывного диапазона обнаружения.

## Безопасная замена

Перед заменой секрета:

1. остановите майнинг;
2. экспортируйте и проверьте текущий секрет;
3. при необходимости скопируйте `wallet.receipts`;
4. запишите важные локальные метки адресов;
5. установите новый секрет;
6. дождитесь завершения поиска адресов и синхронизации.

Никогда не вставляйте секрет на веб-сайте, в отчёте об ошибке, чате или
сообщении службе поддержки.

## Данные контрактов

Вместе с секретом сохраняйте `wallet.contracts.json`, `contract-activity/` и
полный каталог `objects/`, включая `objects/terminals/`. Публичные условия,
журнал и доказательства не восстанавливаются только по секрету. Для согласованной
копии остановите узел. См. [восстановление контрактов](../contracts/receipts-and-recovery.md).

## Токены, NFT и медиа

Текущее владение нативными активами восстанавливается по аутентифицированному
State для адресов кошелька. Сохраняйте `wallet.receipts`, записи native-операций
и `native-media/` вместе с каталогом данных. Так сохраняются локальная история,
подготовленные NFT, изображения и очередь публикации. Перед копированием
закройте кошелёк и остановите его узел.

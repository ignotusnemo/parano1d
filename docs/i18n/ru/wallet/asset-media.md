# Названия и изображения активов

Название, тикер, описание и картинка, публичные метаданные. Определение
токена или запись NFT фиксирует их хеш в State. Перед отображением кошелёк
проверяет описание и изображение по этому хешу. Сам актив определяется
идентификатором токена либо идентификатором коллекции и серийным номером NFT.

При создании выберите локальное изображение PNG, JPEG или WebP размером до
4 МиБ. Кошелёк подготовит статический PNG: до 512 × 512 для логотипа токена
или до 2 048 × 2 048 для NFT. Исходное изображение ограничено 4 096 × 4 096.

Подготовленные файлы сохраняются локально до подтверждения создания. После
подтверждения кошелёк отправит их вместе с публичным чеком в настроенное
хранилище. Хранилище проверит чек своей нодой и сверит точный актив, тип и
хеш. Отправка выполняется в фоне и продолжается после перезапуска кошелька.

По умолчанию кошелёк использует https://tradedata.parano1d.org. Другой сервис можно задать через `NOID_GUI_MEDIA_ORIGIN`.

Другие кошельки скачивают те же файлы и проверяют их по State своей ноды.
Кошелёк проверяет хеш, число байтов и размеры изображения. Описание
отображается как обычный текст. Формат метаданных задаёт фиксированные поля.

Необязательный сайт проекта также входит в хеш метаданных. Разрешены ссылки
HTTPS без логина и пароля. Они открываются во внешнем браузере по нажатию.
Изображения кошелёк получает из настроенного хранилища.

Хранилище содержит неизменяемые каталоги `metadata/`, `images/` и публичные
`proofs/`. Их точную копию можно хранить в Git и восстановить с повторной
проверкой хешей. Сохраняйте каталог `native-media` вместе с резервной копией
кошелька: в нём находятся локальные файлы и очередь ожидающих публикаций.

Если картинка недоступна, кошелёк покажет идентификатор и заглушку. Нода
продолжит проверять владение, балансы, переводы и торги.

[Настройка хранилища](../../../reference/media-service.md) описана в
техническом руководстве на английском языке.

## Автоматическая загрузка

**External data** справа в шапке по умолчанию выключен. **On** включает
изображения токенов и NFT, а также историю цен DEX. Выбор сохраняется между
запусками. При выключении картинки заменяются заглушками. Сохранённые названия
и тикеры доступны в обоих режимах. Создание актива публикует выбранные медиа.
В форме создания выбранное локальное изображение видно сразу.

Текущая цена DEX всегда поступает из своей ноды. При выключенном External data
график показывает движение цены с момента открытия токена. При включении
кошелёк дополнительно загружает свечи подтверждённых сделок с сервиса.
Запросы выполняются для открытого токена. В памяти хранится до 512 блоков.
При выходе из рынка график освобождается. История сохраняется на сервере.

**Settings → Interface → Clear asset cache** очищает скачанные названия и
изображения. Кеш занимает до 64 МиБ. При заполнении старые файлы удаляются.
Материалы созданных активов, очередь публикации и чеки сохраняются.
